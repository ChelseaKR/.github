# Defaults

GitHub reads community health files from this repository for any of my repos that does not
carry its own. A repo with its own `CONTRIBUTING.md`, issue templates or code of conduct
keeps them; this only fills gaps.

Kept deliberately thin. A generic "Bug report" form is furniture: it makes a repository look
maintained without telling anyone anything they could not guess. What is here is the small
set of things that are true across every project I publish, and nothing else.

Projects where an outside contributor could actually do something useful say so in their own
`CONTRIBUTING.md`, with the specific ask.
