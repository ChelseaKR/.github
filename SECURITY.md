# Reporting a vulnerability

**Do not open a public issue.**

Use GitHub's private reporting on the affected repository — *Security* → *Report a
vulnerability* — or email **ckellyreif@gmail.com**.

Please include what you found, roughly how to reproduce it, and what you think it lets
someone do. A rough report is worth far more than no report; you do not need a proof of
concept.

You will get an acknowledgement within a week. These are personal projects maintained by one
person, so I cannot promise a fix window, and I will tell you plainly if something will not be
fixed rather than leaving the thread to go quiet.

If a project processes data about real people, say so in the report — that changes how quickly
I treat it.

I do not run a bounty programme and cannot pay for reports. Credit in the fix commit is
offered by default; tell me if you would rather not be named.
